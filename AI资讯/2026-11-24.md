## 🧠 大模型与 LLM 技术解读

### 1. 🔥 GPT-6.2 Astra / Sol：能力、时延与成本的 API 路由

- **背景**：生产级 Agent 同时需要高难推理/coding 与大量日常多步骤调用，单一旗舰模型难同时优化能力、延迟和成本。
- **问题**：开发者需要可预测的模型分层，并要在工具调用、长任务和预算之间做工程取舍。
- **方法**：OpenAI 提供 Astra 与 Sol 两个型号；均支持文本/图像输入、文本输出，tool calling 要使用 Responses API。changelog 同时给出 2/8 小时 background completion 选项及相对 Standard 的价格折扣。
- **效果**：OpenAI 声称两者在高难任务上优于前代并产生更少输出 token；这是发布方陈述，缺少统一真实负载的跨厂商独立评测。[release notes](https://help.openai.com/en/articles/9624314-model-release-notes) · [API changelog](https://developers.openai.com/api/docs/changelog)

### 2. ⭐ GPT-6.2：把 Preparedness 评估映射为访问边界

- **背景**：模型接入 coding、browser 和 computer-use 后，安全风险不再只是模型卡的附录，而会影响谁能使用哪些能力。
- **问题**：高风险 cyber 辅助不能只靠通用拒答；平台需要把评估结果落实为资格审核和默认限制。
- **方法**：OpenAI 的 system card 说明相应能力评估和部署措施，并描述对较宽松 cyber 访问的额外 vetting 与更严格的默认限制。
- **效果**：该材料是厂商内部评估与部署声明，不是第三方安全认证；其工程价值在于将模型风险分类连接到 API 权限设计。[system card](https://deploymentsafety.openai.com/gpt-6-2-astra-sol/internal-deployment-of-gpt-6.2-astra-and-gpt-6.2-sol)

### 3. ⭐ TideCache：hybrid LLM serving 的 KV cache 变成跨层调度问题

- **背景**：带 global-attention 与 bounded-state 层的 hybrid 模型，使不同层的 KV cache 形态、可迁移性和 HBM 占用不同。
- **问题**：长上下文/多轮 Agent 请求会争抢 HBM；简单常驻限制并发，迁移又可能恶化 TTFT。
- **方法**：论文在 SGLang 中提出 Transparent Cache Pool、layer-wise Cache Streamer 和请求调度器，按层复用 GPU slot 并对可流式 cache 做预取。
- **效果**：作者报告在 GB300/GH200 及多组模型配置上，完成 Agent turns 最多提高 2.04×、P50 token latency 降 20–59%；均为作者实验，暂无独立复现。[arXiv](https://arxiv.org/abs/2611.26619)

### 4. ⭐ AutoMaster：自动设计 post-training 的过程约束

- **背景**：成功轨迹做 SFT/RL 可能同时蒸馏无依据假设、重复验证等低质量过程行为。
- **问题**：只有任务成败标签时，难以定位应该保留或抑制的推理/工具使用习惯。
- **方法**：论文先用自然语言 skill 约束 teacher rollout 的 Skill-FT，再让 AutoMaster 分析 Agent 轨迹、设计 skill、选择数据并接收闭环反馈。
- **效果**：作者称其设置下能改进训练轨迹质量；应继续审查 benchmark、teacher/student 同源性与训练成本，暂无独立评测。[arXiv](https://arxiv.org/abs/2611.26510)

## 🛠️ 工具/开源

- ⭐ **agent-browser**：Vercel Labs 的浏览器自动化 CLI/daemon，提供可访问性快照与语义定位；适合审查 Agent browser 的可观测性和权限边界。[GitHub](https://github.com/vercel-labs/agent-browser)
- ⭐ **GitHub MCP Server**：GitHub 官方 MCP server 是将代码仓库工具接入 Agent 的入口之一；生产环境应使用最小权限 token、仓库 allowlist 与审计日志。[GitHub](https://github.com/github/github-mcp-server)
- ⭐ **AG-UI**：面向 Agent 与用户界面的双向 typed event 协议；接入前应明确事件流中的敏感状态和持久化边界。[GitHub](https://github.com/ag-ui-protocol/ag-ui)
- 📌 **Model Context Protocol**：协议规范是核对 server capability、transport 和版本变化的权威入口；“能连通”不等同安全可上线。[MCP specification](https://modelcontextprotocol.io/specification/2025-06-18)
