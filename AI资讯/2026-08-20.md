## 🧠 大模型与 LLM 技术解读

1. 🔥 OpenAI 暂缓 Astra / frontier RL scaling
   - 背景：frontier model 已经具备更强工具使用、代码执行与网络交互能力，OpenAI 把 OpenAI-Hugging Face incident 与 Astra 的 cyber-critical 信号放在同一安全框架下处理。
   - 问题：传统 sandbox、网络隔离和单轮安全过滤不足以覆盖 agentic training / inference 中的越权访问、数据外泄和对安全机制的规避。
   - 方法：暂停部分 RL training，升级 workload isolation、network isolation、continuous security testing，并把 activation classifiers 与多阶段 automated investigators 用于 chain-of-thought / tool action 监控。
   - 效果：公开材料称最大 frontier RL run 仍暂停，部分 Astra workload 需迁移到更高安全等级后恢复；暂无独立评测。[来源](https://openai.com/index/pacing-model-development-cyber-capabilities/)
2. 🔥 Private Safety Processing 试图兼容 ZDR 与长程 agent 安全
   - 背景：企业客户需要 Zero Data Retention，但更强 agent 的风险往往跨多轮、多账号或长任务才显现。
   - 问题：单次请求级安全系统难以识别渐进式探测、跨交互协同滥用，以及 agent 被要求停止后仍继续行动等风险。
   - 方法：客户内容保留在客户控制基础设施，或由客户密钥加密；自动系统只返回窄定义 safety signal，OpenAI 人员不读取底层 prompt / response。
   - 效果：OpenAI 称该方案正在早期客户测试，计划 9 月发布技术白皮书；暂无独立评测。[来源](https://openai.com/index/offering-zero-data-retention-for-frontier-models/)
3. ⭐ GPT-5.6 的 agent 工程路径：把“推理”从单模型长上下文转向可复用工作流
   - 背景：LLM agent 在浏览器、代码、金融研究和多工具任务中成本压力明显，单纯上更大模型并不经济。
   - 问题：长程任务会重复消耗 token、丢失上下文、把确定性过滤/聚合也塞进模型上下文，导致 latency 与 cost 上升。
   - 方法：使用 reasoning persistence、native compaction、native multi-agent orchestration、programmatic tool calling 和更细粒度 model selection，把确定性数据处理放到代码侧。
   - 效果：OpenAI 公布的案例称 GPT-5.6 Luna 在 BrowseComp 接近 GPT-5.5 Extra High 的分数但成本显著更低，ARC-AGI-3 harness 通过 retained reasoning / compaction 分数提升；这些是厂商与客户案例，暂无独立评测。[来源](https://openai.com/index/builders-guide-to-gpt-5-6/)
4. ⭐ Claude text watermark / SynthID-Text 的合规工程
   - 背景：EU AI Act 推动 AI 生成内容透明度，Anthropic 选择对 Claude 输出加入机器可读文本水印。
   - 问题：文本没有图像/音频那样天然可嵌入的隐写空间，水印要同时满足可检测、低可见性、低质量损失与一定抗编辑能力。
   - 方法：基于 SynthID-Text，在多个近似等价词选择点改变抽样偏好，形成只有持 key 的检测器可识别的统计模式。
   - 效果：Anthropic 表示不影响价格和输出质量；媒体报道已有开发者讨论重写、翻译、paraphrase 等绕过方式，检测鲁棒性暂无独立公开评测。[来源](https://www.theverge.com/ai-artificial-intelligence/980869/anthropic-claude-watermarks-synthid-text-system)
5. ⭐ 论文 `Beyond Teacher Likelihood` 关注 long-context reasoning distillation
   - 背景：更便宜的小模型要承接长上下文推理，需要从强 teacher 获取行为而不仅是 next-token likelihood。
   - 问题：teacher likelihood 可能偏向局部 token 概率，不能保证学生模型在群体、任务或长上下文分布上校准。
   - 方法：论文提出 group-calibrated on-policy distillation，把学生自身 rollout 纳入训练，并关注分组层面的校准。
   - 效果：arXiv 条目显示为 20 页、5 图预印本；具体结果需阅读全文验证，日报不扩展未读结论。[来源](https://arxiv.org/abs/2608.19181)
