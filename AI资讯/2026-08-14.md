## 🧠 大模型与 LLM 技术解读

1. 🔥 GPT-5.6 Sol Ultrafast：低延迟 frontier inference
   - 背景：frontier LLM 已进入 Agent、voice、coding 和实时决策场景，响应延迟正在成为能否替代人工交互的关键瓶颈。
   - 问题：高质量 reasoning model 往往慢，标准推理速度会限制 voice AI、interactive coding、长任务监控等场景。
   - 方法：OpenAI 预览 Ultrafast mode，Cerebras 表示由其 wafer-scale 系统加速 GPT-5.6 Sol，服务层先在 OpenAI API 向部分客户开放。
   - 效果：Cerebras 公开材料称最高 750 output tokens/s、最高 14x faster，并在 HN 讨论中引发大量关注；这些是厂商与社区披露，暂无独立评测。[来源：Cerebras](https://www.cerebras.ai/blog/accelerating-gpt-5-6-sol-ultrafast-with-openai)；[讨论：Hacker News](https://news.ycombinator.com/item?id=49289844)

2. 🔥 Gemini 3.7 Flash：Google 的 Agent/Coding workhorse
   - 背景：Google 需要在 Gemini 系列中同时覆盖高端 Pro 与高频低成本 Flash 场景，尤其是开发者工具和企业自动化。
   - 问题：企业 Agent 需要更好的 coding、web development 与知识工作能力，但不能接受 frontier Pro 模型的成本和延迟。
   - 方法：Google 将 Gemini 3.7 Flash 定位为“most intelligent workhorse model yet for coding and agents”，并在 Google Antigravity 中提供开发者工作流入口。
   - 效果：Google 官方称其在 coding、knowledge work、web development 上有改进，Antigravity 页面给出 $0.75/1M input tokens、$3.75/1M output tokens 的 introductory pricing；公开材料为官方发布，暂无独立评测。[来源：Google Blog](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/)；[来源：Google Antigravity](https://antigravity.google/blog/gemini-3-7-flash-in-google-antigravity)

3. 🔥 Claude Sonnet 5：中价位长任务 Agent 执行层
   - 背景：企业软件工程 Agent、computer use 和 agentic search 正在从 demo 进入真实工作流，模型的成本/能力曲线比单点榜单更重要。
   - 问题：上一代中端模型在长任务 follow-through、工具调用和复杂代码修改上容易中途停止，而 Opus/Fable 级模型成本更高。
   - 方法：Anthropic 提供 effort levels，让用户在 token 消耗、速度和能力之间调节；官方用 BrowseComp 与 OSWorld-Verified 展示 agentic search 和 computer use 曲线。
   - 效果：Anthropic 称 Sonnet 5 相比 Sonnet 4.6 有严格改进，并在部分高 effort 设置接近 Opus 4.8；价格固定为 $2/MTok input、$10/MTok output。上述为官方评测与客户反馈，暂无独立评测。[来源：Anthropic](https://www.anthropic.com/news/claude-sonnet-5)

4. ⭐ Muse Glimmer：本地 Agent 模型与开放权重
   - 背景：Agent 不总能依赖云端 frontier API，企业和个人开发者希望把工具调用、local coding、评测和隐私敏感任务放到本地。
   - 问题：设备端模型通常在 agentic workflow、function calling 和长期运行稳定性上不足，且很多开放模型 license 仍限制商用。
   - 方法：Meta Research 发布 30B 参数 Muse Glimmer，面向 always-on local agent workflows，开放权重并使用 Apache 2.0 license。
   - 效果：Meta 称其在同尺寸 agentic use cases 和 benchmarks 中表现强；这是官方声明，关键 benchmark 细节和第三方复现仍需观察。[来源：Meta AI Research](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model)

5. ⭐ DeepSeek Harness：插件化 Agent runtime
   - 背景：Claude Code、Codex、MCP 与本地 skills 工作流推动 Agent 从“模型能力”转向“运行时、权限、插件、日志和可复现执行”。
   - 问题：Agent 系统难以生产化的核心不是一次性推理，而是插件依赖、行动追踪、上下文注入、权限边界和兼容性演进。
   - 方法：DeepSeek Harness developer preview 采用 plugin-based 架构；公开报道提到 MIT license、Cordis kernel、append-only session log 与完整 traceability。
   - 效果：当前仍是 developer preview，官方/报道均提示 API 与插件会快速变化；适合实验和框架观察，不宜直接生产 pin 版本。[来源：VentureBeat](https://venturebeat.com/technology/deepseek-harness-launches-as-open-source-rival-to-claude-code-alongside-v4-pro-on-api-with-higher-prices)；[来源：Eigent AI](https://www.eigent.ai/blog/deepseek-harness-agent-runtime)
