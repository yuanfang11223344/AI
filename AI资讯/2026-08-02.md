## 🧠 大模型与 LLM 技术解读

### 1. 🔥 GPT-5.6：长上下文、多模态与工具调用的统一化

- **背景：** 商业 LLM 已从 chat model 进入 agentic workflow，用户希望同一个模型处理文本、图像、音频、代码、检索和工具调用。
- **问题：** 主要瓶颈是长上下文下的可靠推理、工具调用链路的稳定性、以及多模态输入被压缩后导致的细节丢失。
- **方法：** OpenAI 公开材料称 GPT-5.6 使用 1M token context window，强化 structured tool use、vision/audio grounding 与代码任务能力；但未披露完整训练数据、架构规模或 RL pipeline。
- **效果：** 发布声明称在 SWE-bench Verified、MMMU 和 long-context retrieval 任务上提升明显；暂无独立评测。来源：[OpenAI GPT-5.6](https://openai.com/index/introducing-gpt-5-6/)

### 2. 🔥 Claude Opus 5：长时间 autonomous coding 的工程化竞争

- **背景：** Claude Code、Codex CLI 与企业 IDE agent 把模型能力从“回答问题”扩展到“持续修改工程仓库”。
- **问题：** 长时间任务容易出现上下文漂移、测试反馈利用不足、工具调用重复和局部 patch 破坏全局约束。
- **方法：** Anthropic 强调 Opus 5 的 extended thinking、代码仓库导航、shell/tool feedback 循环和更强的 instruction following；公开材料未给出完整训练细节。
- **效果：** Anthropic 声称模型在 autonomous coding benchmark 上可持续工作 18 小时，并在内部评测中超过 Opus 4；暂无独立评测。来源：[Anthropic Claude Opus 5](https://www.anthropic.com/news/claude-opus-5)

### 3. ⭐ Gemini 3.0 Ultra：2M token context 对企业知识库的意义

- **背景：** 企业场景常需要一次性读取长合同、代码仓库、会议记录和多模态资料，RAG 与长上下文正在合流。
- **问题：** RAG 依赖 chunking 与 rerank，容易漏掉跨段关系；长上下文模型又面临 attention cost、needle retrieval 和事实一致性挑战。
- **方法：** Google DeepMind 宣称 Gemini 3.0 Ultra 支持 2M token context、视频理解和 Workspace 集成，适合大规模文档推理与多模态检索。
- **效果：** 官方称长文档问答、多模态 reasoning 和代码理解得分提升；暂无独立评测。来源：[Gemini 3.0 Ultra](https://deepmind.google/discover/blog/gemini-3-ultra/)

### 4. ⭐ Mixtral 9x22B v2：MoE 开放模型的效率路线

- **背景：** 开源 LLM 竞争不只看参数规模，也看 inference cost、许可、上下文长度和是否适合私有部署。
- **问题：** Dense model 在高吞吐服务中成本高；小模型虽然便宜，但复杂推理、代码和多语言能力不足。
- **方法：** Mistral 继续使用 sparse MoE，把总参数与激活参数分离，目标是在有限 active parameters 下保持接近大模型的能力。
- **效果：** 官方称其在多语言、代码和推理评测中改进；因为目前主要是发布声明和模型卡，暂无独立评测。来源：[Mixtral 9x22B v2](https://mistral.ai/news/mixtral-9x22b-v2/)

### 5. ⭐ Llama 5 Scout：端侧和私有化 agent 的开放权重路径

- **背景：** 企业和开发者希望把 agent 能力放到本地或私有云，减少数据外发与 token 成本。
- **问题：** 端侧模型通常受限于内存、延迟和工具调用稳定性；多模态 agent 还需要在小模型中保留视觉 grounding。
- **方法：** Meta 公开材料强调 Llama 5 Scout 的多模态输入、较低部署成本和开放权重生态，适合本地 assistant、代码和轻量工具调用。
- **效果：** 官方称在端侧推理和多模态任务上更高效；暂无独立第三方评测。来源：[Meta Llama 5 Scout](https://ai.meta.com/blog/llama-5-scout/)
