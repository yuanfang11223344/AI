## 🧠 大模型与 LLM 技术解读

1. 🔥 Claude Haiku 5.5
   - 背景：企业高频调用、代码补全、客服与数据处理任务需要小模型在成本、延迟和上下文能力之间取得更好平衡。
   - 问题：大模型推理成本高，小模型若能力不足又难以承担生产 Agent 的多步任务。
   - 方法：Anthropic 将 Haiku 5.5 定位为“小模型线”的新一代产品，公开材料强调速度、价格和能力组合；但未公开完整训练数据、架构细节或第三方评测。
   - 效果：官方称这是其最快、最便宜且最有能力的小模型，适合高容量、成本敏感工作；暂无独立评测。来源：[Claude Haiku 5.5](https://www.anthropic.com/claude-haiku-5-5)。
2. 🔥 EmbeddingGemma 2
   - 背景：RAG、企业知识库、Agent memory、代码检索和多模态搜索都依赖 embedding 模型，轻量化会直接影响部署门槛。
   - 问题：通用 embedding 往往在文本、图像、轻量本地部署之间取舍明显，移动端和私有环境更难承受大模型检索栈。
   - 方法：Google 将 EmbeddingGemma 2 描述为 open、lightweight、multimodal embedding model，面向开发者工具与本地/边缘检索场景。
   - 效果：公开材料给出定位与产品形态，具体 benchmark、训练语料与跨模态细分指标仍需看技术报告或第三方复测。来源：[Google Developers Blog](https://blog.google/innovation-and-ai/technology/developers-tools/embeddinggemma-2/)。
3. ⭐ WOVEN: Weaving Visual World Modeling into Multimodal LLMs
   - 背景：多模态大模型在空间、具身、物理和时序推理上仍常失败。
   - 问题：现有 benchmark 往往分散评测这些缺陷，难以验证“视觉状态转移推理”是否是共同瓶颈。
   - 方法：论文提出把 visual world modeling 编织进 MLLM 的训练流程，把视觉转移推理作为共享训练 primitive。
   - 效果：摘要声称该训练 recipe 可让不同模型从不同监督源学习并迁移到不同任务；需要阅读完整实验表后判断泛化强度。来源：[arXiv:2610.12417](https://arxiv.org/abs/2610.12417)。
4. ⭐ ViSkill: Reinforcing VLM Agents with Evolving Visual-Native Skills
   - 背景：Agent 技能库能提升样本效率，但许多方法仍把空间布局和行动状态转换成文本，损失几何结构。
   - 问题：视觉 Agent 的可复用技能如果只用文本表达，很难稳定捕捉空间约束和动作关系。
   - 方法：论文提出 visual-native skill learning，让技能构建与策略优化共同演化，而不是训练后单独整理经验。
   - 效果：摘要宣称可增强 VLM Agent 的可复用技能学习；暂无独立评测。来源：[arXiv:2610.12403](https://arxiv.org/abs/2610.12403)。
5. ⭐ OnTrack: Streaming Structure-Aware Optimal Transport for LLM Agents
   - 背景：LLM Agent 已进入旅行规划、交易、IT 运维等可产生真实成本和风险的任务。
   - 问题：安全监控若由另一个 safeguard agent 逐步审查，会增加成本与延迟；事后日志审计又太晚。
   - 方法：论文用 streaming、structure-aware optimal transport 监控 Agent trajectory，并在运行中介入。
   - 效果：摘要声称目标是在不让每一步都经过昂贵审查的情况下减少不可逆操作风险；具体延迟与误报率需看实验。来源：[arXiv:2610.12375](https://arxiv.org/abs/2610.12375)。
6. 📌 4-bit AdamW optimizer-state quantization
   - 背景：训练大模型时 AdamW optimizer state 占用大量持久存储和内存，低比特量化是降本方向之一。
   - 问题：简单量化会让 moment recurrence 的误差持续传播，影响后续 adaptive update。
   - 方法：论文从 rounding space 重新设计 4-bit AdamW optimizer-state quantization，重点分析接近零的 second moment quantization cell。
   - 效果：摘要说明该方法试图降低量化误差对优化动态的扰动；是否适用于超大规模训练还需看完整实验。来源：[arXiv:2610.12444](https://arxiv.org/abs/2610.12444)。
