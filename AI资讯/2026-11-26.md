## 🧠 大模型与 LLM 技术解读

### 🔥 GPT-6 用于蛋白生物学

- **背景：** LLM 正从文本/代码助手延伸到结构化科研任务，蛋白设计要求模型输出能进入实验筛选链路。
- **问题：** 通用语言模型并不天然保证生物学有效性，且设计候选的湿实验验证成本高。
- **方法：** OpenAI 的技术报告将 GPT-6 的推理与通用代码能力放入蛋白结构设计工作流，材料描述了面向蛋白任务的实验案例。
- **效果：** 公开材料给出研究方结果；尚未看到针对全部任务、由独立第三方完成的统一评测，不能据此宣称已替代专业生物模型。
- **来源：** [技术报告](https://cdn.openai.com/pdf/gpt-6-a-universal-foundation-model-for-protein-biology.pdf)

### 🔥 前沿模型发布阈值与安全评测

- **背景：** 更强的 Agent、工具调用与长程规划能力，让“能力评测”与“可安全发布”不再是同一问题。
- **问题：** 若模型可越出沙箱、连接外部资源或执行高影响工作流，发布前需要界定评测、缓解措施和残余风险。
- **方法：** Axios 报道的是实验室内部争论和员工担忧，而非公开模型卡或标准化评测；可把它视为披露需求的信号，而非性能实证。
- **效果：** 目前没有可复核的模型名称、基准或完整方法，因此暂无独立评测；政策讨论的升温是可观察后果。
- **来源：** [Axios 原报道](https://www.axios.com/2026/11/24/anthropic-openai-unreleased-ai-safety-risks)｜[政策跟进](https://www.axios.com/2026/11/25/democrats-ai-safety-restrictions-openai-anthropic-axios)

### ⭐ Nemotron for Science：科学 Agent 的开放组件化路径

- **背景：** 科研 Agent 往往需要领域模型、数据集、检索/工具和后训练配方共同工作，而不只是单一聊天模型。
- **问题：** 通用模型在化学、材料和仿真工作流中难以直接获得可追溯、可复现实验结果。
- **方法：** NVIDIA 宣布 Nemotron for Science，将 Nemotron 3.5 Super VL、开放化学数据集和后训练 recipes 组合为构建专业 Agent 的资源。
- **效果：** 这是供应商发布材料，价值在于可获得的构件与复现实验入口；跨任务效果仍须等待独立 benchmark 与实际实验室部署。
- **来源：** [NVIDIA 新闻稿](https://nvidianews.nvidia.com/_gallery/download_pdf/6afb290a3d633274ba9a0860/)

### ⭐ MCP/ACP 的异步 Agent 互操作更新

- **背景：** Agent 工具调用逐渐从单轮同步 RPC 转向可恢复的会话、长任务与跨客户端协作。
- **问题：** MCP 请求失败、重复子 Agent 会话和工具调用上下文不清晰，会降低自动化稳定性及审计性。
- **方法：** Claude Agent Client Protocol 0.112.0 增加编辑消息后的同 provider session rewind，并修复放弃后仍阻塞 MCP 请求的问题；0.111.0 为 MCP 请求补充 session/tool-call 命名。
- **效果：** release notes 证明实现变更存在，但未给出端到端可靠性指标；暂无独立评测。
- **来源：** [ACP v0.112.0](https://github.com/agentclientprotocol/claude-agent-acp/releases)
