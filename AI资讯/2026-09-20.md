## 🧠 大模型与 LLM 技术解读

1. 🔥 **OpenAI GPT-6：从模型能力发布转向“部署前证明”。**
   - 背景：frontier 模型进入 agent、代码、长任务和多模态协作场景后，单纯发布参数或 benchmark 已不足以说明可部署性。
   - 问题：核心瓶颈是能力增长与风险控制不同步，尤其是工具调用、自主规划、拒答边界和越权操作风险。
   - 方法：OpenAI 同步发布 GPT-6、deployment safety、system card 与 preparedness addendum，把模型能力、评测、风险分级和部署策略放到同一组公开材料中。
   - 效果：公开材料声称该系列在能力与安全评估上有配套改进；当前仍主要来自官方材料，暂无独立评测。来源：[GPT-6](https://openai.com/index/introducing-gpt-6/)、[System card](https://openai.com/index/gpt-6-system-card/)、[Preparedness addendum](https://openai.com/index/gpt-6-preparedness-addendum/)
2. 🔥 **Anthropic Claude：模型研发任务自动化成为新评测口径。**
   - 背景：大模型公司正把 coding agent、research agent 和 internal tooling 结合，评估模型是否能完成真实研发任务。
   - 问题：传统 benchmark 难以反映 agent 在长链路开发中的可靠性，例如需求理解、代码修改、验证和失败恢复。
   - 方法：公开报道提到 Anthropic 使用内部模型开发任务衡量 Claude 能力，并强调可独立完成任务的比例。
   - 效果：AP 报道给出约 26% 的任务完成说法；因细分任务集、评分器和复现实验未完整公开，应视为公司披露，暂无独立评测。来源：[AP](https://apnews.com/article/ai-jobs-anthropic-claude-2b885d35c05751aa460251dcfd31ef13)、[Anthropic research](https://www.anthropic.com/research)
3. ⭐ **Coding agent harness：工具环境设计本身会改变模型表现。**
   - 背景：coding agent 已从“模型写代码”走向“模型在 harness 中操作 repo、终端、测试与浏览器”。
   - 问题：同一模型在不同 harness 下可能表现差异很大，评测结果容易把环境设计误认为模型能力。
   - 方法：arXiv 论文《An Empirical Study of Harness Design for Coding Agents》研究 coding agent harness 设计变量，强调任务接口、反馈、约束与工具暴露方式。
   - 效果：论文提供实证研究框架；结论应限于论文实验设置，不宜外推到所有 agent。来源：[arXiv:2609.20804](https://arxiv.org/abs/2609.20804)
4. ⭐ **On-Demand Attention：让模型“知道何时回忆”。**
   - 背景：长上下文模型的成本和延迟压力继续上升，尤其是多轮 agent 与知识密集型任务。
   - 问题：全量 attention 或盲目检索会浪费算力，也可能引入无关上下文。
   - 方法：论文《On-Demand Attention: Language Models Know When to Recall》探索按需触发 recall/attention 的机制，让模型在需要时再访问相关信息。
   - 效果：公开摘要表明目标是改善长上下文召回效率；具体收益需看论文实验配置，暂无独立评测。来源：[arXiv:2609.20734](https://arxiv.org/abs/2609.20734)
5. ⭐ **dQwen3.5：Hybrid-Attention Diffusion Language Models 探索非自回归路线。**
   - 背景：LLM 推理成本主要受 token-by-token 自回归生成约束，diffusion language model 是近期替代路线之一。
   - 问题：扩散式文本生成要同时解决并行生成效率、可控性和生成质量稳定性。
   - 方法：论文提出 hybrid-attention diffusion language model，把 Qwen 系列命名空间下的扩散生成与 attention 机制结合。
   - 效果：目前依据为 arXiv 论文；是否能在实际 serving 中优于成熟自回归模型仍需独立复现。来源：[arXiv:2609.20751](https://arxiv.org/abs/2609.20751)
6. 📌 **Agent 过度声称与水印副作用成为评测焦点。**
   - 背景：agent 从聊天进入生产环境后，“模型是否诚实报告能力边界”比单轮问答更关键。
   - 问题：过度声称、虚假确定性、水印或安全训练副作用都可能改变 agent 行为。
   - 方法：相关论文和讨论分别从 overclaiming propensity、watermarking behavior change 等角度审视 frontier LLM agent。
   - 效果：这些工作更多是风险识别与评测方法，不能直接证明某一商业模型不可靠；但值得纳入企业 agent 部署检查表。来源：[arXiv:2609.20812](https://arxiv.org/abs/2609.20812)、[HN 水印讨论](https://news.ycombinator.com/item?id=49742797)
