## 🧠 大模型与 LLM 技术解读

### 1. GPT-6.1 Terra：从“模型名”转向可审计的产品能力

- **背景**：OpenAI 将 GPT-6.1 Terra 列为 10 月产品发布，随后又公告拟收购代码存储公司 Pierre。
- **问题**：代码 Agent 的瓶颈不只在单轮生成，还包括仓库上下文、变更可追溯性和最小权限执行。
- **方法**：官方公开页只确认产品发布与并购事件，未在新闻列表展示训练配方、上下文长度或评测方法；不应据此推断其技术机制。
- **效果**：可核验的是发布/公告事实；关于编程成功率、成本或安全改进，**暂无独立评测**。
- **来源**：[GPT-6.1 Terra 索引](https://openai.com/news/company-announcements/)｜[Pierre 公告](https://openai.com/news/company-announcements/)

### 2. Claude Haiku 5.5：小模型作为 Agent 子任务执行器

- **背景**：多 Agent 系统常将检索、摘要、浏览器操作交给高频子任务，以压低总体延迟和 token 成本。
- **问题**：把所有步骤交给大模型会使高并发工作流的单位任务成本和尾延迟失控。
- **方法**：Anthropic 将 Haiku 5.5 定位为面向 summarization、subagents、browser use 的快速小模型；公告没有披露完整架构或训练细节。
- **效果**：厂商称其为“最快、最强的小模型”；该描述不是跨厂商的独立基准，**暂无独立评测**。
- **来源**：[Anthropic：Introducing Claude Haiku 5.5](https://www.anthropic.com/news?subjects=announcements)

### 3. 企业模型路由：统一控制面而非“单模型胜出”

- **背景**：企业 Agent 往往同时需要闭源前沿模型、开源模型和领域模型。
- **问题**：多模型带来鉴权、审计、数据边界、评测及故障切换的一致性问题。
- **方法**：Google Cloud 公布在统一平台提供多家闭源模型与 200+ 模型，并提供 Anthropic 托管部署选项；这是部署/治理层的集成方式。
- **效果**：公开材料证明供给与部署选项扩大；对效果、成本和模型间可替代性，**暂无独立评测**。
- **来源**：[Google Cloud 公告](https://cloud.google.com/blog/products/ai-machine-learning/what-google-cloud-announced-in-ai-this-month)

### 4. Gemini Robotics Embodied Reasoning 2：把多模态推理接入机器人生命周期

- **背景**：physical AI 需要把视觉/语言推理与仿真、评估、部署链路结合，不能只看聊天基准。
- **问题**：长时程机器人任务受环境变化、执行安全及工具编排制约。
- **方法**：Google Cloud 称 ER 2 可与企业安全、多 Agent 编排和生命周期管理组合；官方摘要未公开模型结构与统一任务评测。
- **效果**：可确认产品可用性与集成方向；实际机器人泛化、安全与吞吐仍需独立现场测试，**暂无独立评测**。
- **来源**：[Google Cloud 公告](https://cloud.google.com/blog/products/ai-machine-learning/what-google-cloud-announced-in-ai-this-month)

### 5. MCP/插件型 Agent：能力扩展与供应链风险同时上升

- **背景**：MCP 服务器和 Agent plugins 正成为编码工作流连接仓库、浏览器及 SaaS 的主要接口。
- **问题**：工具调用会扩大权限、prompt injection 和依赖供应链攻击面，且工具输出可快速耗尽上下文。
- **方法**：本周 MCP 生态索引列出可在写入/编辑后执行设计系统检查的插件，并提醒其目录数据来自公开注册表、GitHub、npm/PyPI，未代替安全审计。
- **效果**：下载量和 HN 讨论只能说明关注度，不能证明安全性或生产可靠性；上线前应审查代码、权限和隔离策略。
- **来源**：[MCP Morning](https://mcpmorning.com/archive/2026-11-05/)｜[HN 讨论](https://news.ycombinator.com/)

## 🖥️ 芯片与互连

- 🔥 **224G SerDes + UCIe 进入 CPO 集成链**：Lightmatter/Synopsys 披露把 3nm 224G SerDes 与 UCIe IP 接入 Passage 3D CPO。关键不是单一 IP 指标，而是电—光界面与封装共同决定的链路预算、热设计与可制造性；HVM-ready 为厂商表述。[来源](https://lightmatter.co/press-release/lightmatter-collaborates-with-synopsys-to-integrate-advanced-interface-ip-with-its-passage-co-packaged-optics-platform/?asPDF=1)
- ⭐ **400G/λ 硅微环调制器的研究进展**：论文报告 wafer-scale silicon MRM 在 PAM6 下达到 400 Gb/s/λ 开眼图，并给出不同工作模式与能耗数据。结果是单器件/实验链路证据，不能直接等同量产模块规格。[arXiv](https://arxiv.org/abs/2509.01555)
- ⭐ **SOH PIC 指向 1.6T/3.2T-DR8**：研究者报告 1.6T-DR8 PIC 的 224G PAM4 开眼图，另一个变体面向 3.2T-DR8/400G/λ；材料与工艺可扩展性仍是从实验走向量产的关键变量。[arXiv](https://arxiv.org/abs/2509.24825)
- 📌 **单芯片 1.024 Tb/s 硅光接收机**：该工作使用 GlobalFoundries 45CLO CMOS-photonic 工艺，讨论高码率 AI 链路应用；应关注其封装、热漂移和完整系统 BER，而非仅看聚合速率。[arXiv](https://arxiv.org/abs/2507.12452)
- 📌 **互连路线的共同约束**：Qualcomm 投资者材料将 die-to-die、PAM4 electrical/optical SerDes、CPO/NPO、AEC/LPO 等按距离分层；它是厂商路线图，不是标准冻结或部署统计。[资料](https://www.qualcomm.com/content/dam/qcomm-martech/dm-assets/documents/Investor-Day-2026_TPialis_Data-Center.pdf)
